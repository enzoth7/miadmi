# Mi Admi

Mi Admi es una aplicación web de finanzas personales pensada para Uruguay.  
Permite a los usuarios organizar su dinero, estimar ingresos/egresos y acceder a herramientas útiles como cálculo de aguinaldo, despido, seguro de desempleo, entre otras.

> Proyecto en desarrollo activo.

---

## 🛠 Stack

- Next.js
- React
- TypeScript / JavaScript
- Supabase
- Vercel
- MercadoPago (suscripciones)
- Resend (emails)

---

## 🚀 Desarrollo local

Instalar dependencias:
npm install

Levantar el entorno de desarrollo:
npm run dev

La app corre en:
http://localhost:3000

---

## 🏗 Build de producción

Para verificar que el build de producción funcione correctamente:

npm run build
npm run start

---

## 🌐 Deploy

El deploy a producción se realiza automáticamente desde GitHub a Vercel al pushear a la rama main.

No se recomienda deployar manualmente desde la CLI salvo casos puntuales.

---

## 🔐 Variables de entorno

Las variables de entorno se manejan exclusivamente desde Vercel.
Los archivos .env* están ignorados por Git.
