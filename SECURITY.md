# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Mi Admi**, please report it responsibly.

### How to report
Send an email to:

📧 **soporte@miadmi.com**

Please include as much detail as possible:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Potential impact
- Screenshots or logs (if helpful)

## Responsible Disclosure
Please do not publicly disclose security issues until they have been reviewed and addressed.

We appreciate responsible disclosures and will do our best to respond in a timely manner.

---

Thank you for helping keep Mi Admi secure.
